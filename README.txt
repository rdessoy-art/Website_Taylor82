Mark Taylor #82 static website

Files:
- index.html
- styles.css
- robots.txt
- assets/ (logos and photos)

To publish on GitHub Pages:
1. Upload these files to the repository root, or into a docs folder if GitHub Pages is configured that way.
2. The custom domain is marktaylor82.com (see CNAME). Point the domain's DNS at GitHub Pages and enable HTTPS in the repository's Pages settings.
3. Register the site in Google Search Console and submit https://marktaylor82.com/sitemap.xml.
